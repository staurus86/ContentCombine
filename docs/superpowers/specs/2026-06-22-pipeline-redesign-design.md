# Редизайн пайплайна: «Тренды → Кейсы → Telegram» (бесплатный режим)

**Дата:** 2026-06-22
**Статус:** утверждён к планированию
**Проект:** ContentCombine (`C:\Opencode-test\ContentCombine`)
**UI-стандарт:** визуальный слой реализуется по скиллу **global-design** (по требованию пользователя).
**Constraint поставки:** всё (Ф0–Ф4) выкатывается **ОДНИМ коммитом = один редеплой Railway** —
чтобы не гонять сборки. Реализуем и тестируем локально/на проде через `DATABASE_PUBLIC_URL`,
коммитим и пушим один раз.

## Цель / воркфлоу
Пользователь ведёт Telegram-канал по SEO+AI. Нужен пайплайн для скоростного поиска
трендов и публикации. Дневной сценарий: открыл → **утром смотрю собранные сюжеты
(тренды)** → вижу **кто о чём пишет** → читаю **кейсы** → **публикую в Telegram**.
Платные функции (LLM, Keys.so) сейчас не подключаем — всё, что от них зависит, скрыть.

## Важное ограничение релиза (граница со спекой архитектуры)
Ф0–Ф4 — это **UX/product-redesign текущего ContentCombine, а НЕ архитектурный рефактор
`engine/`/`niches/`** из базового спека (`2026-06-22-content-combine-design.md`). В этом
коммите **не** делаем расцепление engine/niches, **не** переносим модули, **не** меняем
структуру движка, **не** строим универсальный GUI ниш, **не** трогаем донор IgroNews.
Только бесплатный рабочий режим «Тренды → Кейсы → Telegram» на текущей кодовой базе.
Расцепление engine/niches — отдельный будущий релиз.

## Решения (согласованы)
1. **Статусы** — убрать из UI совсем (нет колонки «Статус», нет фильтров по статусам).
   Движок статусы внутри использует — просто не показываем.
2. **Telegram** — кнопка + предпросмотр поста; реальная отправка включается, когда дан
   токен бота и id канала.
3. **Кейсы** — ручная закладка 📌 на любой новости/сюжете + авто-накопление всего с
   тегом «Исследование/Кейс» (`research`); кейсы исключены из фрешнесс-чистки.
4. **Кто о чём пишет** — внутри сюжетов (источники+теги уже есть) + «облако тем дня».

## Структура вкладок (было 11 → станет 7 видимых)
Видимых 7: **🔥 Тренды · 📰 Лента · 📌 Кейсы · 📊 Аналитика · 🩺 Здоровье · ⚙ Настройки · 🗑 Удалённые**.
«Удалённые» оставляем отдельной вкладкой — нужны для контроля фрешнесс-чистки.
- **🔥 Тренды** (storylines) — главная по умолчанию; выводим из скрытых.
- **📰 Лента** (editorial) — онлайн-поток; чистим от статусов.
- **📌 Кейсы** — новая; закладки, не удаляются.
- **📊 Аналитика**, **🩺 Здоровье**, **⚙ Настройки**, **🗑 Удалённые** — оставляем.
- **Скрыть** (закомментировать в разметке, не удалять): Обогащённые (`news`),
  Финал (`final`), Контент (`editor`), Виральность (`viral`), Очередь (`queue`).
- **Кнопки скрыть:** ✎ Рерайт, 🚀 Полный автомат (LLM). **Оставить:** 📋 Без LLM,
  ☰ Sheets, 📊 XLSX.

- В строке Ленты — только действия: **📌 В кейсы · 📤 В Telegram · 🗑 Скрыть**.
  Колонки: Источник · Заголовок · Скор · Вирал · Свежесть · Объём · Теги · Дата.
- **XLSX-экспорт**: переименовать лист `IgroNews Export` → `ContentCombine Export` и

- Верхняя KPI-строка переосмыслить: *Новых за 24ч · Сюжетов · В кейсах · Источников активно*.

### Ф2 — Тренды (главная) + облако тем дня
- `storylines` делаем дефолтной вкладкой, показываем. **JS-состояние, не только HTML:**
  у `.tab[data-tab="storylines"]` ставим `active` (снять с `editorial`), у `#panel-storylines`
  — `active`; если в `localStorage` сохранена прошлая вкладка — она **не** должна перебивать
  новый дефолт (сбросить/игнорировать сохранённое значение при первом заходе после релиза);
  hard reload `/` открывает именно «🔥 Тренды».
- Сверху «облако тем дня»: топ-теги за 24–48ч, размер/цвет по числу источников.
  Источник данных: `tags_data` активных новостей + distinct sources на тег.
  Новый API: `GET /api/topic_cloud?hours=48`.
- Карточка сюжета: + действия 📌 / 📤; сортировка по числу источников (есть).

### Ф3 — Кейсы
- БД: `_add_column_if_missing(cur, "news", "is_case", "INTEGER DEFAULT 0")` + индекс
  `CREATE INDEX IF NOT EXISTS idx_news_case ON news(is_case)`.
- Ручная закладка: `POST /api/news/case {news_ids, on}` → `is_case=1/0`.
- Авто: при простановке тега-кейса (в `checks/pipeline.py` после `auto_tag`) выставлять `is_case=1`.
  **Правило «это кейс»:** тег считается кейсом, если `id == "research"` ИЛИ label/slug
  совпадает с `research|исследование|кейс` (case-insensitive). Эту же функцию использует
  и ручной, и авто-путь.
- **Бэкфилл существующих — Python-проходом по `tags_data`** (НЕ DB-JSON-запросом: SQLite/PG
  ведут себя по-разному): прочитать `news_analysis.tags_data`, распарсить JSON в Python,
  применить правило, проставить `is_case=1`.
- **Защита от чистки:** `soft_delete_stale_news`, `cleanup_old_news`, `cleanup_short_news`
  добавляют `AND COALESCE(is_case,0)=0` (кейсы не удаляются никогда, пока не снимут 📌).
- Вкладка «Кейсы»: `get_news_unified` с фильтром `?cases=1` (WHERE `is_case=1`),
  сорт по дате; кнопка снять 📌.

### Ф4 — Telegram-предпросмотр
- **Отправка plain text БЕЗ `parse_mode`** (надёжно, без багов экранирования). Жирный `**`
  показываем только в предпросмотре/копировании, в Telegram уходит чистый текст.
  (MarkdownV2 с обязательным escaping `title/summary/url/hashtags` — опционально позже.)
- Формат: `{title}` (строка) · пустая строка · `{summary}` (обрезка ~600 симв.) · пустая ·
  `{hashtags}` · `{url}`. **Хэштеги безопасно:** из тегов/сущностей, транслит/удаление
  не-`\w`, без пробелов, max ~5. **Лимит 4096 символов** — обрезка с `…`.
- Кнопка 📤 → модалка предпросмотра (редактируемый textarea) + «Скопировать» + «Отправить».
- `POST /api/telegram/publish {news_id|text}`: если `config.TELEGRAM_BOT_TOKEN` и
  `config.TELEGRAM_PUBLISH_CHANNEL` заданы — отправка ботом; иначе `{"status":"no_token"}`,
  UI показывает «канал не подключён, текст скопирован».
- Настройка `TELEGRAM_PUBLISH_CHANNEL` (env + ⚙) — пусто по умолчанию.

## Критерии успеха
- Поиск по репозиторию `IgroNews|IGR NEWS|igronews` **не находит user-visible вхождений**
  (допустимы только внутренние legacy-докстринги/переменные, напр. `TELEGRAM_SESSION`).
  Новая иконка в табе браузера и в шапке.
- Видны 7 вкладок; платные скрыты; LLM/статусных кнопок нет; деплой SUCCESS (**один** редеплой).
- Тренды — стартовая (и после hard reload); облако тем дня отражает реальные теги/источники.
- 📌 кладёт в Кейсы; **кейс старше 14 дней с `is_case=1` НЕ удаляется** ни одной cleanup/
  freshness-функцией (обязательный тест: создать такую запись → прогнать все чистки → жива).
- 📤 даёт корректный предпросмотр; без токена — копирование (`no_token`), с токеном — отправка,
  длинный пост режется до 4096.
- Лента без статусов/статус-actions; KPI показывают осмысленные числа.

## Обязательные smoke-проверки перед единственным пушем
Тестируем локально/на проде через `DATABASE_PUBLIC_URL`, и только потом один commit+push:
- `/` после hard reload открывает «🔥 Тренды».
- В UI нет `IgroNews / IGR NEWS / igronews` в видимых местах.
- Платные вкладки и LLM-кнопки скрыты; в Ленте нет статус-фильтра, статус-колонки и
  approve/reject/auto-approve.

- `POST /api/news/case` ставит и снимает `is_case`.
- Новость с `is_case=1` старше 14д не удаляется cleanup/freshness-чисткой.
- `POST /api/telegram/publish` без токена → `no_token`, UI копирует текст; с токеном — отправка,
  длинный пост режется до лимита.
- `python -m compileall` по всем изменённым модулям — чисто.
