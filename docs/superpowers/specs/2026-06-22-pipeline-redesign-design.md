# Редизайн пайплайна: «Тренды → Кейсы → Telegram» (бесплатный режим)

**Дата:** 2026-06-22
**Статус:** утверждён к планированию
**Проект:** ContentCombine (`C:\Opencode-test\ContentCombine`)
**UI-стандарт:** визуальный слой реализуется по скиллу **global-design** (по требованию пользователя).
**Constraint поставки:** всё (Ф0–Ф4) выкатывается **ОДНИМ коммитом = один редеплой Railway** —
чтобы не гонять сборки. Реализуем и тестируем локально/на проде через `DATABASE_PUBLIC_URL`,
коммитим и пушим один раз.

## Цель / воркфлоу
Пользователь ведёт Telegram-канал по SEO+AI. Нужен пайплайн для скоростного поиска
трендов и публикации. Дневной сценарий: открыл → **утром смотрю собранные сюжеты
(тренды)** → вижу **кто о чём пишет** → читаю **кейсы** → **публикую в Telegram**.
Платные функции (LLM, Keys.so) сейчас не подключаем — всё, что от них зависит, скрыть.

## Решения (согласованы)
1. **Статусы** — убрать из UI совсем (нет колонки «Статус», нет фильтров по статусам).
   Движок статусы внутри использует — просто не показываем.
2. **Telegram** — кнопка + предпросмотр поста; реальная отправка включается, когда дан
   токен бота и id канала.
3. **Кейсы** — ручная закладка 📌 на любой новости/сюжете + авто-накопление всего с
   тегом «Исследование/Кейс» (`research`); кейсы исключены из фрешнесс-чистки.
4. **Кто о чём пишет** — внутри сюжетов (источники+теги уже есть) + «облако тем дня».

## Структура вкладок (было 11 → станет 6 видимых)
- **🔥 Тренды** (storylines) — главная по умолчанию; выводим из скрытых.
- **📰 Лента** (editorial) — онлайн-поток; чистим от статусов.
- **📌 Кейсы** — новая; закладки, не удаляются.
- **📊 Аналитика**, **🩺 Здоровье**, **⚙ Настройки**, **🗑 Удалённые** — оставляем.
- **Скрыть** (закомментировать в разметке, не удалять): Обогащённые (`news`),
  Финал (`final`), Контент (`editor`), Виральность (`viral`), Очередь (`queue`).
- **Кнопки скрыть:** ✎ Рерайт, 🚀 Полный автомат (LLM). **Оставить:** 📋 Без LLM,
  ☰ Sheets, 📊 XLSX.

### Ф1 — Каркас вкладок + Лента без статусов
- Скрыть платные вкладки/кнопки (CSS `display:none` / комментарий в разметке).
- Лента: убрать колонку «Статус» и статус-фильтры; действия в строке →
  **📌 В кейсы · 📤 В Telegram · 🗑 Скрыть**. Колонки: Источник · Заголовок · Скор ·
  Вирал · Свежесть · Объём · Теги · Дата.
- Верхняя KPI-строка переосмыслить: *Новых за 24ч · Сюжетов · В кейсах · Источников активно*.

### Ф2 — Тренды (главная) + облако тем дня
- `storylines` делаем дефолтной вкладкой, показываем.
- Сверху «облако тем дня»: топ-теги за 24–48ч, размер/цвет по числу источников.
  Источник данных: `tags_data` активных новостей + distinct sources на тег.
  Новый API: `GET /api/topic_cloud?hours=48`.
- Карточка сюжета: + действия 📌 / 📤; сортировка по числу источников (есть).

### Ф3 — Кейсы
- БД: `news.is_case INTEGER DEFAULT 0` (`_add_column_if_missing`).
- Ручная закладка: `POST /api/news/case {news_ids, on}` → `is_case=1/0`.
- Авто: при простановке тега `research` (в `checks/pipeline.py` после `auto_tag`)
  выставлять `is_case=1`. Бэкфилл существующих с тегом research.
- **Защита от чистки:** `soft_delete_stale_news` и `cleanup_old_news`/`cleanup_short_news`
  добавляют условие `AND COALESCE(is_case,0)=0`.
- Вкладка «Кейсы»: `get_news_unified` с фильтром `?cases=1` (WHERE is_case=1),
  сорт по дате; кнопка снять 📌.

### Ф4 — Telegram-предпросмотр
- Формат поста (без LLM): `**{title}**\n\n{description|summary}\n\n{hashtags из тегов}\n{url}`.
- Кнопка 📤 → модалка предпросмотра (редактируемый текст) + «Скопировать» + «Отправить».
- `POST /api/telegram/publish {news_id|text}`: если `config.TELEGRAM_BOT_TOKEN` и
  `config.TELEGRAM_PUBLISH_CHANNEL` заданы — отправка ботом; иначе `{"status":"no_token"}`,
  UI показывает «канал не подключён, текст скопирован».
- Настройка `TELEGRAM_PUBLISH_CHANNEL` (env + ⚙) — пусто по умолчанию.

## Критерии успеха
- Нигде в UI нет «IgroNews» — везде ContentCombine; новая иконка в табе браузера и шапке.
- Видны только 6 вкладок; платные скрыты; LLM-кнопок нет; деплой SUCCESS (**один** редеплой).
- Тренды — стартовая; облако тем дня отражает реальные теги/источники.
- 📌 кладёт в Кейсы; кейсы не исчезают после фрешнесс-чистки (>14д).
- 📤 даёт корректный предпросмотр поста; без токена — копирование, с токеном — отправка.
- Лента без статусов, действия работают; KPI показывают осмысленные числа.

## Не делаем (YAGNI)
LLM-рерайт, Keys.so-обогащение, авто-постинг по расписанию (пока), отдельная
тепловая карта Источники×Темы (только облако тем + источники в сюжетах).
